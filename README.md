# COVID-FI-Mortality

Public repository of R code and data for reproducing the analysis in the companion manuscript titled "County-level food insecurity and COVID-19 mortality in the United States: A spatial analysis using R-INLA"

## Folder Descriptions

**/01-Data-Raw**: Raw data files that are read in in the "R/01-data-merge.R" script. (Not included in this repository0--as it is not meant to host data)

**/02-Data-Wrangled**: Intermediate datasets created in several R scripts dedicated to merging and wrangling data files. (Not included in this repository0--as it is not meant to host data)

**/03-Data-Rodeo**: Contains the final analytic datasets. (Not included in this repository0--as it is not meant to host data)

**/04-Tables-Figures**: Contains figures and tables generated throughout the analysis.

**/R**: Contains all `.R` files with code to reproduce all data-wrangling steps, analyses, tables, and figures.
